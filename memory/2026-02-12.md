## Created: Expense Tracker Skill
- **Location**: `~/.openclaw/workspace/skills/expense-tracker/`
- **Purpose**: Track expenses from receipt photos with OCR, auto-categorization, SQLite/Excel storage, and chart reporting
- **Features**:
  - OCR from receipt photos (using pytesseract)
  - Auto-extract: merchant, total, date, items
  - Auto-categorization: Makanan, Transport, Belanja, Hiburan, Kesehatan, Utilitas, Lainnya
  - Dual storage: SQLite (default) + Excel export with charts
  - Generate charts: pie, bar, timeline

**Usage:**
```bash
~/.pyenv/versions/3.10.14/bin/python3 ~/.openclaw/workspace/skills/expense-tracker/scripts/expense.py add --manual
~/.pyenv/versions/3.10.14/bin/python3 ~/.openclaw/workspace/skills/expense-tracker/scripts/expense.py add /path/to/receipt.jpg
~/.pyenv/versions/3.10.14/bin/python3 ~/.openclaw/workspace/skills/expense-tracker/scripts/expense.py list
~/.pyenv/versions/3.10.14/bin/python3 ~/.openclaw/workspace/skills/expense-tracker/scripts/expense.py summary --bulan 2
~/.pyenv/versions/3.10.14/bin/python3 ~/.openclaw/workspace/skills/expense-tracker/scripts/expense.py export
```
