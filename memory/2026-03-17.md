# 2026-03-17 - Memory Log

## Slack Token Usage Fix

### Problem
Token usage naik cepat (27% → 32% dalam beberapa jam) karena OpenClaw memproses **setiap message** dari bot Afya Appointment Alert di channel Slack #afya-bgst.

### Root Cause
- `channels.slack.groupPolicy = "open"` → Semua message di semua channel diproses
- Bot Afya Appointment Alert ngirim error 500 messages yang panjang (ada request body, JSON response, patient data)
- Setiap message consume ribuan token untuk processing

### Solution
Ubah konfigurasi Slack di `~/.openclaw/openclaw.json`:

**Before:**
```json
"groupPolicy": "open"
```

**After:**
```json
"groupPolicy": "allowlist",
"channels": {
  "general": {},
  "random": {},
  "errors": {},
  "engineering": {},
  "dev": {},
  "team": {}
}
```

**Hasil:** Channel #afya-bgst sekarang di-ignore, token usage akan turun drastis.

### Changes Applied
- [x] Heartbeat frequency: 30m → 2h
- [x] Slack groupPolicy: open → allowlist
- [x] Channel allowlist: general, random, errors, engineering, dev, team
- [x] Restart OpenClaw daemon

### Reference
- Docs: `channels.slack.channels` menggunakan object format (bukan array)
- Channel ID untuk #afya-bgst tidak dimasukkan ke allowlist
