## Hermina Doctor Search Feature

### API Integration Learned
Successfully integrated with Hermina Public API for doctor search:
- **Base URL**: `https://api.herminahospitals.com/api/v1/`
- **Key Endpoints**:
  - `GET /public/hospitals?q={branch}` - Find hospital by branch name
  - `GET /public/doctors?hospital_id={id}&speciality_id={spec}&q={query}` - Search doctors
  - `GET /public/doctors/{slug}/schedules` - Get doctor schedules

### Query Patterns
1. Find hospital ID first: `/public/hospitals/?q=pasteur` → returns hospital_id
2. Search doctors by specialty: `/public/doctors?hospital_id=7&speciality_id=gigi`
3. **Get schedules (CORRECT):** `/public/doctors/{slug}/schedules?schedule_type=executive&type=table`
   - `schedule_type`: `executive` (Padma/pribadi) or `specialist` (BPJS/asuransi)
   - `type`: `table` for schedule display (NOT `calendar` - calendar is for time slots)
   - Returns: Array of schedules by hospital branch with `day`, `from_time`, `to_time`, `clinic_name`

### Local Database Schema (hermina_development)
- `doctors` - full_name, speciality_id, hospital_id
- `hospitals` - name, branch, id
- `schedules` - doctor_id, hospital_id, day, from_time, to_time
- `specialities` - name_id, name_en
- `hospital_doctors` - junction table

### Schedule Response Format (type=table)
```json
{
  "Hermina Pasteur": [
    {
      "day": "monday",
      "from_time": "12:00",
      "to_time": "14:00",
      "time": "12:00-14:00",
      "schedule_type": "executive",
      "clinic_name": "Klinik Bedah Umum Padma",
      "appointment_method": "afya"
    }
  ]
}
```
- `day`: lowercase english (monday, tuesday, etc)
- `time`: Combined display string "HH:MM-HH:MM"
- `schedule_type`: executive (Poli Padma) vs specialist (regular)
- `clinic_name`: Full clinic name

### Clinic Types
- **Executive (Padma)**: Private pay/penjaminan - `schedule_type=executive`
- **Specialist**: BPJS/Insurance - `schedule_type=specialist`
